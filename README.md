KESTREL-5
Conceptual 5-kN LOX/RP-1 Liquid Rocket Engine
TALON-5 is an undergraduate propulsion engineering project focused on the preliminary design and analysis of a conceptual liquid rocket engine for a high-altitude sounding rocket application.

The project develops a one-dimensional, steady-state computational model to investigate rocket engine performance, thermochemistry, nozzle flow, and thermal behavior. The resulting design is translated into a preliminary SolidWorks CAD model.

Project Objectives
-Develop a 1-D liquid rocket engine performance model in MATLAB
- Analyze LOX/RP-1 thermochemistry using NASA CEA
- Calculate chamber and nozzle performance
- Investigate the effects of chamber pressure, mixture ratio, and nozzle expansion ratio
- Develop a preliminary thermal model
- Perform propulsion design trade studies and optimization
- Create a corresponding conceptual SolidWorks engine design
- Validate analytical predictions against established references
