KESTREL-5
Conceptual 5-kN LOX/RP-1 Liquid Rocket Engine
Propulsion engineering project focused on the preliminary design and analysis of a conceptual liquid rocket engine. It follows the criteria of Embry Riddles Rocket Development Lab Project Mountain Spirit goal of reaching the Karman line.

The project develops a one dimensional, steady state computational model.

Project Objectives
- Develop a 1D liquid rocket engine performance model in MATLAB
- Analyze LOX/RP-1 thermochemistry using NASA CEA
- Calculate chamber and nozzle performance
- Investigate the effects of chamber pressure, mixture ratio, and nozzle expansion ratio
- Develop a thermal model
- Perform propulsion design optimization
- Create a SolidWorks engine design
- Validate analytical predictions against established references

Project Structure
- MATLAB/          Models
- CAD/             SolidWorks models and drawings
- Data/            Reference data
- Figures/         Generated plots and visualizations
- Validation/      Model validation
- Report/          Technical Writing
